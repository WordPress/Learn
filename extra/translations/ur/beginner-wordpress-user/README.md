# Urdu translation: Beginner WordPress User

Urdu (`ur`) translation of the 24-lesson *Beginner WordPress User* course on
Learn WordPress, tracked under course issue
[#3613](https://github.com/WordPress/Learn/issues/3613).

Each lesson below is a side-by-side table: English on the left, Urdu on the right.

## Which folder to use

| Folder | What it is | Use it for |
| --- | --- | --- |
| [`upload-ready/`](upload-ready/) | The reviewer copy. Metadata, glossary, title, transcript and quiz only, with the translator scaffolding stripped out. | **Upload these to Google Docs and share with the reviewer.** |
| [`docx/`](docx/) | The full working workbook, including the how-to notes, thumbnail task and pre-review checklist. | Your own record of the work. |
| [`md/`](md/) | The same content as Markdown tables. | Row-by-row comments in the pull request, since GitHub cannot comment inside a `.docx`. |

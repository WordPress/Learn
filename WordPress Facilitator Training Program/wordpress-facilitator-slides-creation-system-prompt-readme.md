# WordPress Facilitator Slides Creation — System Prompt Guide

This system prompt brings the WordPress Facilitator Slides Creation workflow to any AI assistant — including ChatGPT, Gemini, Claude.ai, and others. It gives the AI the instructions it needs to guide you through creating a complete workshop slide deck from your course materials.

---

## What's in the File

The file `wordpress-facilitator-slides-creation-system-prompt.md` contains a full set of instructions covering:

- A step-by-step workflow for gathering your inputs and building the deck
- WordPress brand colors, fonts, and writing style rules
- Slide structure rules for every slide type (day dividers, session headers, activity slides, etc.)
- A quality checklist the AI runs before delivering the output

---

## How to Use It

### ChatGPT (via Custom GPT)

Best option if you want a reusable, shareable setup for your team:

1. Go to [chat.openai.com](https://chat.openai.com) and click **Explore GPTs → Create**
2. Switch to the **Configure** tab
3. Paste the full contents of `wordpress-facilitator-slides-creation-system-prompt.md` into the **Instructions** field
4. Give your GPT a name (e.g., "WordPress Facilitator Slides Creator") and save
5. Share the GPT link with your team — anyone with the link can use it

**For a one-off session (no Custom GPT needed):**
1. Start a new chat
2. Paste the full contents of the file as your first message, prefaced with: "Please use the following as your instructions for this conversation:"
3. The AI will confirm it understands and you can proceed

## What You'll Need

Regardless of which AI you use, have these ready before you start:

**Course content** — a document with the learning content, topics, lessons, and learning objectives. Paste it into the chat or upload the file if the AI supports file uploads.

**Facilitation guide** — a document with session timing, activity descriptions, transition language, and talking points. Paste or upload.

**Audience & goals** — a few sentences describing who the participants are and what they should leave with.

**Brand information** — all presentations should follow the [WordPress brand guidelines](https://wordpress.org/brand/) and the WordPress Figma design system. The system prompt includes the documented WordPress brand values (colors, fonts, writing style) as its baseline. Do not substitute a custom brand — these slides are for the WordPress Facilitator Training Program and should always reflect WordPress visual identity.

---

## What You'll Get

The AI will guide you through reviewing an outline before generating anything, then produce the full deck as structured slide-by-slide text, including:

- Every slide's heading and content
- Speaker notes for every slide
- A quality check summary before delivery

Since this version runs in a chat interface rather than a desktop app, the output is text-based rather than a ready-made `.pptx` file. You can copy the slides directly into PowerPoint or Google Slides, or ask the AI to generate a Python script to build the file automatically (if your AI supports code execution).

---

## Tips for Best Results

- **Paste your full documents** rather than summarizing them — the more detail the AI has, the more accurate the output.
- **Review the outline** before approving it. The AI will always show you the full slide plan and wait for your go-ahead before generating.
- **Request revisions by slide** — for example, "Update the activity slide for Session 3" rather than asking it to redo the whole deck.
- **If the AI loses track** of the instructions mid-session, paste the system prompt again and ask it to continue.
